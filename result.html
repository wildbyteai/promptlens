用 ChatGPT Plus 分析这张图

PromptLens 已在本地准备好图片和分析指令。你可以手动上传，也可以授权 PromptLens 尝试填入 ChatGPT 页面。

  1. 下载处理后的图片。
  2. 复制分析指令。
  3. 打开 ChatGPT，上传图片并粘贴指令。
  4. 在 ChatGPT 中发送并保留结果。
实验功能： 「尝试发送到 ChatGPT」会请求访问 chatgpt.com，用于尝试把图片和指令填入 ChatGPT 输入框。不会读取或保存 ChatGPT 网页端回复，也不会自动发送。ChatGPT 页面变化时可能失败，失败后可继续手动下载图片和复制指令。
隐私边界： PromptLens 不会把辅助模式图片发送给 API 或自有后端。你主动上传到 ChatGPT 后，图片和指令受 OpenAI 的隐私政策、账号设置和使用限制约束。
